## Definition Functions

### `defineDomain(id, setup, options?)`

Creates and returns a `Domain` instance. The setup function runs synchronously; `state()` registrations are collected and used to build the domain.

```typescript
function defineDomain<TContext, TEdges>(
  id: string,
  setup: () => DomainSetupResult<TContext>,
  options?: DefineDomainOptions<TContext>
): Domain<TContext, TEdges>
```

#### Parameters

**`id`** `string`

Unique domain identifier.

**`setup`** `() => DomainSetupResult<TContext>`

Synchronous setup function. `state()` calls inside register states. Must return a `DomainSetupResult`:

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `context` | `TContext` | Yes | — | Initial context object |
| `initial` | `string` | Yes | — | ID of the initial state |
| `strict` | `boolean` | No | `false` | When `true`, `follow()` throws on unknown events instead of returning `status: 'ignored'` |
| `errorPolicy` | `ErrorPolicy` | No | — | Default error policy for handlers in this domain |

**`options`** `DefineDomainOptions<TContext>` *(optional)*

Additional configuration:

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `tracer` | `Tracer` | No | Tracer instance to attach |
| `merge` | `(prev: TContext, patch: Partial<TContext>, metadata: MergeMetadata) => TContext` | No | Custom context merge function; called instead of the default shallow spread |

#### Return value

`Domain<TContext, TEdges>`

---

### `definePipeline(id, setup, options?)`

Creates and returns a `Pipeline` instance. The setup function runs synchronously; `node()` registrations are collected.

```typescript
function definePipeline<TContext>(
  id: string,
  setup: () => PipelineSetupResult,
  options?: DefinePipelineOptions<TContext>
): Pipeline<TContext>
```

#### Parameters

**`id`** `string`

Unique pipeline identifier.

**`setup`** `() => PipelineSetupResult`

Synchronous setup function. `node()` calls inside register nodes. Must return a `PipelineSetupResult`:

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `initial` | `string` | Yes | ID of the first node to execute |

**`options`** `DefinePipelineOptions<TContext>` *(optional)*

Additional configuration:

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `tracer` | `Tracer` | No | Tracer instance to attach |
| `errorPolicy` | `ErrorPolicy` | No | Default error policy for node actions |
| `merge` | `(prev: TContext, patch: Partial<TContext>, metadata: MergeMetadata) => TContext` | No | Custom context merge function; called instead of the default shallow spread |

#### Return value

`Pipeline<TContext>`

---

### `MergeMetadata`

Passed as the third argument to a custom `merge` function.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `phase` | `string` | Yes | Execution phase (e.g. `'edge-action'`, `'node-action'`, `'on-enter'`) |
| `domainId` | `string` | No | ID of the enclosing domain, when in a domain context |
| `pipelineId` | `string` | No | ID of the enclosing pipeline, when in a pipeline context |
| `nodeId` | `string` | No | ID of the current pipeline node |
| `stateId` | `string` | No | ID of the current domain state |
| `event` | `string` | No | Event name that triggered the transition |

## Registration Helpers

These functions are only valid inside an active `defineDomain` or `definePipeline` setup function. Calling them outside throws `PlexisError` with code `BUILDER_CLOSED`.

### `state(id, def)`

Registers a state in the current domain builder scope.

```typescript
function state<TContext>(id: string, def: StateNodeDef<TContext>): void
```

#### Parameters

**`id`** `string`

Unique state identifier.

**`def`** `StateNodeDef<TContext>`

State definition:

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `edges` | `Record<string, EdgeDef<TContext>>` | No | Map of event name to edge definition |
| `onEnter` | `(ctx: TContext, input: StateHookInput) => PatchLike` | No | Hook called when entering this state |
| `onExit` | `(ctx: TContext, input: StateHookInput) => PatchLike` | No | Hook called when exiting this state |
| `pipeline` | `Pipeline<TContext>` | No | Pipeline to run on state entry, after `onEnter` |
| `terminal` | `boolean` | No | When `true`, this is a terminal state |
| `metadata` | `Record<string, unknown>` | No | Arbitrary user-defined metadata |

#### Return value

None (`void`).

---

### `edge(def)`

Creates an `EdgeDef` for use in a state's `edges` map.

```typescript
function edge<TContext>(def: EdgeDef<TContext>): EdgeDef<TContext>
```

#### Parameters

**`def`** `EdgeDef<TContext>`

Edge definition:

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `target` | `string` | Yes | ID of the target state |
| `guard` | `(ctx: TContext, input: GuardInput) => boolean \| Promise<boolean>` | No | Guard predicate; transition is blocked when `false` |
| `action` | `(ctx: TContext, input: TransitionActionInput) => PatchLike` | No | Context patch handler run during the transition |
| `pipeline` | `Pipeline<TContext>` | No | Pipeline to run as part of the transition, after the action |
| `metadata` | `Record<string, unknown>` | No | Arbitrary user-defined metadata |

#### Return value

`EdgeDef<TContext>` — the same definition object, for inline use in `edges` maps.

---

### `node(id, def)`

Registers a node in the current pipeline builder scope.

```typescript
function node<TContext>(id: string, def: PipelineNodeDef<TContext>): void
```

#### Parameters

**`id`** `string`

Unique node identifier.

**`def`** `PipelineNodeDef<TContext>`

Node definition:

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `action` | `(ctx: TContext, input: PipelineActionInput) => PatchLike` | No | Context patch handler for this node |
| `forks` | `PipelineForkDef<TContext>[]` | No | Ordered list of fork conditions; first match wins |
| `terminal` | `boolean` | No | When `true`, execution stops after this node |
| `metadata` | `Record<string, unknown>` | No | Arbitrary user-defined metadata |

#### Return value

None (`void`).

### `fork(condition, target, options?)`

Creates a `PipelineForkDef` for use in a node's `forks` array.

```typescript
function fork<TContext>(
  condition: ((ctx: TContext, input: PipelineConditionInput) => boolean | Promise<boolean>) | undefined,
  target: string | Pipeline<TContext>,
  options?: { label?: string; metadata?: Record<string, unknown> }
): PipelineForkDef<TContext>
```

#### Parameters

**`condition`** `((ctx, input) => boolean | Promise<boolean>) | undefined`

Fork predicate. Pass `undefined` for an unconditional forward edge; otherwise the first fork whose condition returns `true` is followed.

**`target`** `string | Pipeline<TContext>`

ID of the target node, or a sub-pipeline to embed.

**`options`** `{ label?: string; metadata?: Record<string, unknown> }` *(optional)*

Optional label and metadata attached to the fork.

#### Return value

`PipelineForkDef<TContext>`:

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `target` | `string \| Pipeline<TContext>` | Yes | ID of the target node, or a sub-pipeline |
| `condition` | `(ctx: TContext, input: PipelineConditionInput) => boolean \| Promise<boolean>` | No | Fork predicate; `undefined` means unconditional |
| `label` | `string` | No | Human-readable label for this fork path |
| `metadata` | `Record<string, unknown>` | No | Arbitrary user-defined metadata |

---

### `terminal(def?)`

Creates a `PipelineNodeDef` with `terminal: true`. Optionally accepts a partial node definition (excluding `terminal`).

```typescript
function terminal<TContext>(
  def?: Omit<PipelineNodeDef<TContext>, 'terminal'>
): PipelineNodeDef<TContext>
```

#### Parameters

**`def`** `Omit<PipelineNodeDef<TContext>, 'terminal'>` *(optional)*

Optional action, forks, and metadata for the terminal node.

#### Return value

`PipelineNodeDef<TContext>` with `terminal: true`.

## Tracer

### `createTracer(options?)`

Creates a `Tracer` instance. See the [Tracer guide](/guides/tracer/) for full documentation.

```typescript
function createTracer(options?: TracerOptions): Tracer
```

#### Parameters

**`options`** `TracerOptions` *(optional)*

Tracer configuration:

| Field | Type | Required | Default | Description |
| --- | --- | --- | --- | --- |
| `enabled` | `boolean` | No | — | When `false`, the tracer does not record events |
| `captureContext` | `boolean \| 'before' \| 'after' \| 'both'` | No | `false` | Whether to snapshot context on each event; `'before'`, `'after'`, or `'both'` capture snapshots before/after the handler |
| `maxEvents` | `number` | No | `10000` | Maximum number of events held in memory; oldest events are dropped when the cap is reached |
| `clock` | `() => number` | No | — | Custom timestamp function; defaults to an internal monotonic clock |
| `idFactory` | `() => string` | No | — | Custom event ID generator; defaults to an internal UUID factory |
| `onSubscriberError` | `(error: unknown) => void` | No | — | Called when a subscriber throws; subscriber errors are always isolated from the tracer |

#### Return value

`Tracer`:

| Member | Parameters | Returns | Description |
| --- | --- | --- | --- |
| `captureContext` | — | `boolean \| 'before' \| 'after' \| 'both'` | Reflects the `captureContext` option in effect |
| `subscribe(listener)` | `listener: (event: TraceEvent) => void` | `() => void` | Listen to live trace events; returns an unsubscribe function |
| `record(partial)` | `partial: Partial<TraceEvent> & Pick<TraceEvent, 'traceId' \| 'level' \| 'type'>` | `TraceEvent \| undefined` | Record a trace event; returns `undefined` when recording is disabled |
| `history()` | — | `TraceEvent[]` | All recorded events |
| `traces()` | — | `string[]` | All trace IDs |
| `byTraceId(id)` | `id: string` | `TraceEvent[]` | Events for one trace |
| `export(format)` | `format: 'json' \| 'text' \| 'tree'` | `unknown` | Export trace data in the given format |
| `clear()` | — | `void` | Remove all recorded events |

## Errors

### `PlexisError`

`PlexisError extends Error`. See the [Error Handling guide](/guides/error-handling/) for full documentation.

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `code` | `string` | Yes | One of the error codes below |
| `domainId` | `string` | No | Domain ID, when the error originated in a domain |
| `pipelineId` | `string` | No | Pipeline ID, when the error originated in a pipeline |
| `nodeId` | `string` | No | Node ID, when the error is node-specific |
| `context` | `unknown` | No | Snapshot of the context at the time of the error |

**Error codes**

| Code | Description |
| --- | --- |
| `UNKNOWN_EVENT` | `follow()` was called with an event that has no matching edge and `strict` is `true` |
| `STATE_MISMATCH` | `followFrom()` was called but the current state does not match the expected state |
| `UNKNOWN_INITIAL_STATE` | The `initial` ID from the domain setup does not match any registered state |
| `UNKNOWN_INITIAL_NODE` | The `initial` ID from the pipeline setup does not match any registered node |
| `UNKNOWN_TARGET_STATE` | An edge `target` does not match any registered state |
| `UNKNOWN_TARGET_NODE` | A fork `target` does not match any registered node |
| `UNKNOWN_NODE` | `inspectNode()` was called with an ID that does not exist |
| `BUILDER_CLOSED` | A registration helper was called outside an active `defineDomain` or `definePipeline` setup function |

### `PatchLike`

The type a handler may return to patch context:

```typescript
type PatchLike<TContext> = Partial<TContext> | void | null | undefined
```

Return a `Partial<TContext>` to merge changes into the context. Return `void`, `null`, or `undefined` for no change. The default merge strategy is a shallow spread: `{ ...prev, ...patch }`.

---

### `ErrorPolicy`

```typescript
type ErrorPolicy = 'throw' | 'return' | 'trace-and-return'
```

| Value | Description |
| --- | --- |
| `'throw'` | Re-throw the error; the caller receives a rejected promise |
| `'return'` | Return a result with `status: 'error'` instead of throwing |
| `'trace-and-return'` | Record the error in the trace and return `status: 'error'` |

---
